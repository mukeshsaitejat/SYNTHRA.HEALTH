 Overview:

Synthra.Health is a next-gen AI hospital management & patient appointment platform.
It connects hospitals, doctors, and patients with a secure, fast, and verified-only ecosystem.

No fake reviews.
No messy booking systems.
No outdated hospital software.

Just pure automation + clean UI + AI everywhere.

 Features
1) Hospital Dashboard

View/manage appointments in real time

Doctor schedules, departments, patient history

Smart analytics (wait time prediction, load estimation)

Clean & modern UI

2) Patient App

Book instant appointments

QR-based appointment verification

Prescription history

Light/Dark premium UI

3) Verified-Only Reviews

Patients can review only if they actually visited

No bots, no fake ratings, no manipulation


4) Security

JWT Authentication

Encrypted patient data

Bcrypt password hashing

CORS managed & protected

Role-based access
